# DevAssist CLI

DevAssist CLI is a lightweight, open-source tool designed to help developers understand and maintain their codebases.

## Features

- Scan project directories and list files.
- Identify Python files and test files.
- Generate a basic project health report.
- Exclude common dependency and cache directories.
- Provide a foundation for future AI-powered development tools.

## Motivation

Small open-source projects often lack simple tools to understand their structure and assess their organization. DevAssist CLI aims to make this process easier, faster, and more accessible.
